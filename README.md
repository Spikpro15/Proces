# PC Monitor USB — автономный мониторинг ПК на старом Android

Полностью автономная связка **ПК (Windows)** + **старый Android по USB-проводу**. Без MSI Afterburner, без RTSS и без Wi-Fi задержек.

## Что выводится по умолчанию
1. **FPS в игре** (автономно через Intel PresentMon ETW + 1% low и название активной игры)
2. **Загрузка процессора (%)**
3. **Температура процессора (°C, Tctl/Tdie для Ryzen)**
4. **Загрузка видеокарты (%)**
5. **Температура видеокарты (°C)**
6. **Загрузка ОЗУ (% и ГБ)**

Дополнительно в 1 клик (прямо с телефона по кнопке `⚙ Виджеты` или на ПК в трее -> `Настройки виджетов`) можно включить VRAM, питание CPU/GPU (Вт) и частоты CPU/GPU (МГц).

## Как собрать готовые `.apk` и `.exe`

### Вариант 1 (самый простой — без установки Android Studio и .NET SDK)
1. Создай любой **приватный** репозиторий на GitHub и залей туда всё содержимое этого архива (включая папку `.github`).
2. Открой вкладку **Actions** -> выбери запуск **Build PC Agent & Android APK**.
3. Через 2–3 минуты внизу появятся два готовых файла:
   - `PCMonitor-Android-APK` (`app-debug.apk`) — скинь на телефон и установи.
   - `PCMonitor-Windows-EXE` (`PCMonitorAgent.exe` + `setup_tools.bat`) — распакуй на ПК.

### Вариант 2 (собрать локально на своём ПК)
- **ПК-агент**: установи [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) и запусти `pc_agent\build_and_run_pc.bat`. Скрипт сам скачает официальные `adb.exe` и `PresentMon.exe` в `tools\`, соберёт проект и запустит агент в трее.
- **Android APK**: открой папку `android_app` в [Android Studio](https://developer.android.com/studio) -> меню `Build` -> `Build APK(s)`.

## Первый запуск (1 минута)
1. На старом Android включи **Отладку по USB**:
   - *Настройки -> О телефоне -> нажми 7 раз на «Номер сборки»*
   - *Настройки -> Для разработчиков -> Отладка по USB (Вкл)*
2. Подключи телефон к ПК кабелем и на телефоне нажми **«Разрешить отладку по USB»** (поставь галочку «Всегда разрешать»).
3. На ПК запусти `setup_tools.bat` (один раз, чтобы скачать `adb.exe` и `PresentMon.exe`), затем запусти `PCMonitorAgent.exe` (от имени администратора — это нужно для чтения температуры CPU и ETW-событий FPS).
4. Открой **PC Monitor USB** на телефоне — он сам подхватит соединение по USB, уберёт шторку, не даст экрану гаснуть и сразу покажет 6 метрик.
