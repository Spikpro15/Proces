# PC Monitor USB






Превращает старый Android-телефон в проводную настольную станцию мониторинга ПК, медиаплеер и Stream Deck по обычному USB-кабелю. Полностью автономно — без MSI Afterburner, без RTSS, без Wi-Fi задержек и с одновременной зарядкой телефона.

## Возможности

- **Полный кастом Bento-сетки (`http://127.0.0.1:8765/`):** интерактивная студия экрана в браузере на ПК. Перетаскивай блоки мышкой, меняй размер (`W± / H±`), сетку (`4×3`, `5×3`, `3×2`, `4×4`), цвет каждого блока, темы (`Тёмная`, `AMOLED`, `Тёплая Spide`, `Киберпанк`), масштаб шрифта и загружай свой фон под полупрозрачные стеклянные плитки. Есть готовые пресеты (`Стиль TikTok`, `Игровой`, `Стример`).
- **Мониторинг железа и живые графики:** FPS и 1% low в играх, загрузка и температура CPU/GPU, RAM, VRAM, скорость сети (`↑` отдача для стримов / `↓` загрузка), питание в ваттах и частоты — со встроенными живыми графиками на плитках и красной пульсацией при перегреве или нехватке памяти.
- **Часы, погода и статус устройства:** встроенный блок с часами, секундами, датой, погодой (автоопределение по IP или выбранный вручную город через Open-Meteo), именем ПК и уровнем заряда телефона. Есть автоматический настольный режим часов вне игры.
- **Плеер Windows:** мини-плеер прямо на главном экране + полноэкранный плеер по свайпу вверх с размытым фоном из обложки трека, автоподбором цвета акцента, живым эквалайзером, полосой прогресса, переключением треков и громкостью (работает со Spotify, Spide, Яндекс Музыкой, YouTube в браузере и другими плеерами).
- **Stream Deck + OBS Studio WebSocket:** по свайпу влево открывается панель быстрых кнопок с настраиваемыми горячими клавишами Windows и живой строкой OBS (таймер эфира, старт/стоп стрима и записи, переключение сцен).
- **Отчёты просадок FPS после игры:** агент привязывается к процессу игры (PID), не сбивается при альт-табах и после выхода сохраняет HTML-разбор в папку `reports\` со средним FPS, худшим 1% low, пиками температур/памяти и таблицей просадок с вероятной причиной.
- **Удобство каждый день:** автозапуск с Windows без окна UAC (через Планировщик задач), защита экрана от выгорания (Pixel Shift), блокировка засыпания и **обновление APK на телефоне в 1 клик по USB** прямо из студии или приложения.

## Поддерживаемое железо и стек

| Компонент | Как работает |
| :--- | :--- |
| **Процессор (AMD / Intel)** | [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) + драйвер [PawnIO](https://github.com/namazso/PawnIO.Setup/releases) (резерв: Win32 API) |
| **Видеокарта (NVIDIA / AMD / Intel)** | LibreHardwareMonitor (для NVIDIA есть резерв через `nvidia-smi`) |
| **FPS в играх** | [Intel PresentMon](https://github.com/GameTechDev/PresentMon) (системные события ETW, без внедрения в процесс игры) |
| **Погода** | [Open-Meteo](https://open-meteo.com/) (бесплатно, без API-ключей) |
| **OBS Studio** | Встроенный клиент OBS WebSocket v5 (OBS Studio 28+) |
| **Связь с телефоном** | [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) (`adb reverse tcp:8765 tcp:8765`) |

## Быстрая установка (3 шага)

Скачай готовый архив **`PCMonitorUSB-ReadyToUse.zip`** со страницы [Releases](https://www.google.com/search?q=https://github.com/Spikpro15/Proces/releases) и распакуй в любую папку на ПК (например, `C:\PCMonitor`).

### 1. Установи драйвер PawnIO (для температуры CPU)
Запусти `PawnIO_setup.exe` из распакованной папки -> нажми левую иконку (монитор со стрелкой вниз) -> дождись завершения и закрой окно. Если PawnIO уже установлен, шаг можно пропустить.

### 2. Подготовь Android-телефон
1. Перекинь `PCMonitor-Android.apk` на телефон и установи (при будущих обновлениях переносить файл вручную больше не придётся — всё ставится в 1 клик по USB).
2. Включи **Отладку по USB**:
   - *Настройки -> О телефоне -> нажми 7 раз на «Номер сборки»* (на Xiaomi/Redmi — «Версия MIUI / HyperOS»).
   - *Настройки -> Для разработчиков -> Отладка по USB (Вкл)*.
3. Подключи телефон кабелем к ПК и подтверди на экране запрос **«Разрешить отладку по USB»** (отметь «Всегда разрешать»).

### 3. Запусти агент на ПК
Запусти `PCMonitorAgent.exe` (подтверди права администратора для датчиков температуры и счётчика FPS) — программа свернётся в трей возле часов. Открой **PC Monitor USB** на телефоне: через 2–3 секунды появится зелёный статус **«● USB»**.

Двойной клик по иконке в трее (или переход на `http://127.0.0.1:8765/`) откроет Bento-студию экрана, настройки OBS, погоды, автозапуска и отчёты просадок.

## Подключение OBS Studio (по желанию)

1. В OBS Studio открой *Инструменты -> Настройки сервера WebSocket* и поставь галочку **«Включить сервер WebSocket»**.
2. В студии на `http://127.0.0.1:8765/` впиши порт (по умолчанию `4455`) и пароль (если включён) и нажми **«Сохранить OBS»**.
3. На экране Stream Deck (свайп влево на телефоне) автоматически появится панель управления стримом, записью и сценами.

## Если телефон не подключается

Открой папку `tools\platform-tools\`, в адресной строке Проводника введи `cmd`, нажми Enter и выполни:

```cmd
adb devices
```

- **`unauthorized`** — разблокируй телефон и нажми «Разрешить отладку по USB» (если окно не появилось, в *Для разработчиков* нажми «Отозвать доступ к отладке по USB», переключи тумблер и переткни провод).
- **Пустой список** — проверь, что кабель поддерживает передачу данных (не только зарядку), переключи режим USB на телефоне на **«Передача файлов (MTP)»**, а если в Диспетчере устройств Windows висит жёлтый треугольник на Android/ADB — установи драйвер через *Необязательные обновления Windows* или [Google USB Driver](https://developer.android.com/studio/run/win-usb).

## Структура проекта

```text
├── pc_agent/               # Windows-агент (.NET 8, WinForms tray, Bento Studio, SMTC, OBS WS v5, Weather, SessionAnalyzer)
├── android_app/            # Android-клиент (Kotlin, Android 7.0+, Bento Grid, Next-Gen Player, Stream Deck)
└── .github/workflows/      # Автосборка PCMonitorUSB-ReadyToUse.zip через GitHub Actions
```

## Сборка из исходников

Репозиторий настроен на автоматическую сборку через **GitHub Actions** (`.github/workflows/build.yml`): при каждом коммите собираются Android APK, автономный Windows-агент и итоговый архив `PCMonitorUSB-ReadyToUse` со всеми утилитами.

Для локальной сборки нужны [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (для `pc_agent`) и [Android Studio](https://developer.android.com/studio) / JDK 17 (для `android_app`).
