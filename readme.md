# PC Monitor USB






Превращает старый Android-телефон в проводной экран мониторинга ПК по обычному USB-кабелю. Полностью автономно — без MSI Afterburner, без RTSS, без Wi-Fi задержек и с одновременной зарядкой телефона.

## Возможности

- **6 основных показателей из коробки:** FPS в игре (с 1% low и названием игры), загрузка и температура CPU, загрузка и температура GPU, загрузка ОЗУ (в % и ГБ).
- **Дополнительные датчики в один клик:** видеопамять (VRAM), потребление CPU/GPU в ваттах, частоты CPU/GPU.
- **Живой редактор экрана на ПК:** открой `http://127.0.0.1:8765/` (или дважды кликни по иконке в трее) — там встроен интерактивный мини-телефон, где плитки можно перетаскивать мышкой, скрывать и добавлять на лету.
- **Плеер Windows по свайпу вверх:** свайпни вверх на экране телефона, чтобы увидеть текущий трек, переключать музыку и регулировать громкость Windows (работает со Spotify, Spide, Яндекс Музыкой, YouTube в браузере и другими плеерами).
- **Отчёты просадок после игры:** агент привязывается к процессу игры (PID), не сбивается при альт-табах и после выхода сохраняет HTML-разбор в папку `reports\` — со средним FPS, худшим 1% low, пиками температур/памяти и таблицей просадок с вероятной причиной (упор в VRAM, ОЗУ, CPU/GPU, перегрев или шейдеры).
- **Удобный режим экрана на Android:** полноэкранный режим без шторки, блокировка засыпания экрана, кнопка поворота и режим пониженной яркости для OLED.

## Поддерживаемое железо

| Компонент | Как читается |
| :--- | :--- |
| **Процессор (AMD / Intel)** | [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) + драйвер [PawnIO](https://github.com/namazso/PawnIO.Setup/releases) (резерв: Win32 API) |
| **Видеокарта (NVIDIA / AMD / Intel)** | LibreHardwareMonitor (для NVIDIA также есть резерв через `nvidia-smi`) |
| **FPS в играх** | [Intel PresentMon](https://github.com/GameTechDev/PresentMon) (системные события ETW, без внедрения в процесс игры) |
| **Связь с телефоном** | [Android SDK Platform-Tools](https://developer.android.com/tools/releases/platform-tools) (`adb reverse tcp:8765 tcp:8765`) |

## Быстрая установка (3 шага)

Скачай готовый архив **`PCMonitorUSB-ReadyToUse.zip`** со страницы [Releases](https://www.google.com/search?q=https://github.com/Spikpro15/Proces/releases) (или из последнего успешного запуска во вкладке **Actions**) и распакуй в любую папку на ПК (например, `C:\PCMonitor`).

### 1. Установи драйвер PawnIO (для температуры CPU)
Запусти `PawnIO_setup.exe` из распакованной папки -> нажми левую иконку (монитор со стрелкой вниз) -> дождись завершения и закрой окно. Если PawnIO уже установлен, этот шаг можно пропустить.

### 2. Подготовь Android-телефон
1. Перекинь `PCMonitor-Android.apk` на телефон и установи.
2. Включи **Отладку по USB**:
   - *Настройки -> О телефоне -> нажми 7 раз на «Номер сборки»* (на Xiaomi/Redmi — «Версия MIUI / HyperOS»).
   - *Настройки -> Для разработчиков -> Отладка по USB (Вкл)*.
3. Подключи телефон кабелем к ПК и на экране телефона подтверди запрос **«Разрешить отладку по USB»** (отметь «Всегда разрешать»).

### 3. Запусти агент на ПК
Запусти `PCMonitorAgent.exe` (потребуются права администратора для датчиков температуры и счётчика FPS) — программа свернётся в трей возле часов. Открой **PC Monitor USB** на телефоне: через 2–3 секунды сверху загорится зелёное **«● USB подключён»**.

## Если телефон не подключается

Открой папку `tools\platform-tools\`, в адресной строке Проводника введи `cmd`, нажми Enter и выполни:

```cmd
adb devices
```

- **`unauthorized`** — разблокируй телефон и нажми «Разрешить отладку по USB» (если окно не появилось, в *Для разработчиков* нажми «Отозвать доступ к отладке по USB», переключи тумблер и переткни провод).
- **Пустой список** — проверь, что кабель поддерживает передачу данных (не только зарядку), переключи режим USB на телефоне на **«Передача файлов (MTP)»**, а если в Диспетчере устройств Windows висит жёлтый треугольник на Android/ADB — установи драйвер через *Необязательные обновления Windows* или [Google USB Driver](https://developer.android.com/studio/run/win-usb).

## Структура проекта

```text
├── pc_agent/               # Windows-агент (.NET 8, WinForms tray, HTTP/WebSocket, SMTC, SessionAnalyzer)
├── android_app/            # Android-клиент (Kotlin, Android 7.0+, OkHttp WebSocket)
└── .github/workflows/      # Автосборка PCMonitorUSB-ReadyToUse.zip через GitHub Actions
```

## Сборка из исходников

Репозиторий настроен на автоматическую сборку через **GitHub Actions** (`.github/workflows/build.yml`): при любом изменении кода собираются APK, автономный Windows-агент и итоговый архив `PCMonitorUSB-ReadyToUse` со всеми утилитами.

Для локальной сборки нужны [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0) (для `pc_agent`) и [Android Studio](https://developer.android.com/studio) / JDK 17 (для `android_app`).
